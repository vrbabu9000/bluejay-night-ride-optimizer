# Midterm presentation, content draft v0.4 (23 Oct 2026)

This is a content revision of the midterm talk for an audience meeting the work for the first time. The presentation is planned at about 27 minutes and must stay under 30; questions are not assumed to fit inside that allocation. The v0.3 package (`../v0.3/`), v0.2 (`../`) and the original proposal deck are preserved unchanged.

## Reading order
1. [content_storyboard.md](content_storyboard.md): the narrative spine, the visual language, the old-to-new slide mapping, and per-slide content and timing.
2. [BlueJay_Midterm_v0.4.pptx](BlueJay_Midterm_v0.4.pptx) and [BlueJay_Midterm_v0.4_preview.pdf](BlueJay_Midterm_v0.4_preview.pdf).
   - 28 main slides, a backup divider (29) and B1–B9 (30–38).
   - The PDF is exported from the PPTX with LibreOffice.
3. [speaking_script.md](speaking_script.md): per slide, the context, the exact narration and the transition; also the timing estimate, speaker splits, presenter reference and Q&A jump table.
4. [slide_explanations.md](slide_explanations.md): the preparation handbook. Per slide it gives the evidence, assumptions, design choices, likely questions and working links to the methodology, spec, model and decision-log sections.
5. [reviews/](reviews/): the [technical review](reviews/technical_review.md) of the disputed interpretations and the final wording, the [first-time listener](reviews/review_first_time_listener.md) and [presenter/professor](reviews/review_presenter_professor.md) reviews, and the [resolution record](reviews/resolution_record.md).

```
python3 docs/presentations/midterm/v0.4/resolve_links.py           # resolves handbook link tokens; checks every relative link and anchor
```

**Declared inputs** (read-only; all ignored by git and present locally):
- `data/processed/obs_*` (April aggregates);
- `data/scenarios/v2/L5/` (frozen pilot inputs);
- `outputs/sim/batch_L5_v1/`, `outputs/sim/L4_R3-2/` and `outputs/sim/d53_experiment/`.

**Figures.**
- `figures/proposal_slide{07,08,10,11}.png` come from the *committed* proposal deck (`git show HEAD:docs/presentations/BlueJayNightRide_Proposal.pptx`), rendered with LibreOffice at 110 dpi. The dashboard map regions were masked in the image files, because the April imagery is restricted.

**No dependency on earlier versions.** The v0.3 build read v0.2's ignored `data/deck_numbers.json` for three backups; `make_numbers.py` now regenerates those values itself.

**Generated versus intermediate.**
- *Required generated artifacts:* the PPTX, the preview PDF and the figures.
- *Reproducible intermediate:* `derived/numbers.json`, which is not ignored and is small. It is tracked so that the deck can be rebuilt where `outputs/` is absent.
